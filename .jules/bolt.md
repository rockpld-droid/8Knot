## 2024-03-20 - [Optimize dataframe row-by-row apply]
**Learning:** Using `pandas.DataFrame.apply()` with `axis=1` for date interval counting is extremely slow (O(M*N)) because it iterates Python lambda functions row-by-row and filters the main dataframe for each date. This pattern occurs in visualization files like `issues_over_time.py` and `pr_over_time.py` when computing the number of open issues/PRs for each point in time.
**Action:** When computing counts over time in Pandas (e.g., number of open items at time T), prefer `numpy.searchsorted` instead of `.apply(axis=1)` with dataframe filtering. Sort the `created_at` and `closed_at` arrays once, then use `np.searchsorted` to find the number of created items minus the number of closed items up to each time `T`. Note: convert timezone-aware datetimes to timezone-naive before extracting `.values` for proper `datetime64` array optimization.
